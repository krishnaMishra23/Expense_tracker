💰 Expense Tracker - Project Statement
📌 Problem Statement

Managing daily expenses manually can make it difficult to keep track of where money is being spent. It can also be difficult to calculate total spending and compare it with a monthly budget.

💡 Proposed Solution

The Expense Tracker is a Python-based command-line application that allows users to record and manage their daily expenses.

The application provides options to add, view, search, summarize, and delete expenses. It also allows users to set a monthly budget and check their spending against it.

🎯 Objectives

Record daily expenses

Calculate total spending

Organize expenses by category

Search expenses by category and date

View monthly expense summaries

Set and check a monthly budget

Store expense data for future use

🛠️ Technologies

Python

File Handling

Lists and Dictionaries

Functions and Modules

Basic Python Testing
